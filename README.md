
# Django Homework Blog

Учебный проект блога на Python и Django.

## Описание проекта

Сайт содержит три страницы:

- Главная — приветствие и краткий анонс публикации.
- О блоге — информация о блоге и его назначении.
- Страница поста — полный текст статьи.

Страницы используют наследование HTML-шаблонов
от base.html.

Для оформления используются CSS-стили и изображения.

## Требования

Для запуска проекта необходимы Python и pip.
Для клонирования репозитория используется Git.

## Установка проекта

1. Клонировать репозиторий:

   git clone https://github.com/EugeniaPetrushina/django-homework-blog.git

2. Перейти в папку проекта:

   cd django-homework-blog

3. Создать виртуальное окружение:

   python -m venv venv

4. Активировать окружение (Windows PowerShell):

   .\venv\Scripts\Activate.ps1

5. Установить зависимости:

   python -m pip install -r requirements.txt

## Запуск сервера

1. Перейти в папку Django-проекта:

   cd blogsite

2. Применить миграции базы данных:

   python manage.py migrate

3. Запустить сервер:

   python manage.py runserver

4. Открыть сайт в браузере:

   http://127.0.0.1:8000/

## Страницы сайта

Главная:
http://127.0.0.1:8000/

О блоге:
http://127.0.0.1:8000/about/

Страница поста:
http://127.0.0.1:8000/post/

Для остановки сервера нажать Ctrl + C.

## Книга отзывов

В проект добавлена книга отзывов.

Страница доступна по адресу:

http://127.0.0.1:8000/reviews/

Посетитель может оставить отзыв, указав:

- ФИО (обязательное поле)
- Email (обязательное поле)
- Текст отзыва (обязательное поле)

После отправки отзыв сохраняется в базе данных
со значением "Проверено" = False.

На сайте отображаются только отзывы,
одобренные администратором.

## Администрирование отзывов

Для работы с административной панелью
необходимо создать суперпользователя.

В папке blogsite выполнить команду:

python manage.py createsuperuser

После запуска сервера открыть:

http://127.0.0.1:8000/admin/

Войти под созданным администратором.

В разделе "Guestbook → Отзывы" можно:

- Просматривать отзывы
- Изменять их
- Устанавливать галочку "Проверено"
- Фильтровать проверенные и непроверенные отзывы

После установки галочки "Проверено"
и сохранения изменений отзыв становится
виден на странице книги отзывов.
